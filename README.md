## Paleta global (versión 9)
En el administrador, el color 1 controla el fondo; el 2 controla todos los textos salvo los códigos, precios y textos auxiliares del administrador (color 4); el 3 controla los fondos de recuadros en todas las pantallas, incluidos los botones y las entradas de formulario. Los recibos impresos y el visor de cámara mantienen sus fondos funcionales. Pulsa GUARDAR CAMBIOS para sincronizar la configuración con Firebase.
